Estas son las tecnologías que estoy aprendiendo para el desarrollo web.

Hola, ¿qué tal? Soy Aneudy Muñoz S. En esta página compartiré con ustedes algunas de las tecnologías que estoy aprendiendo para crear un sitio web.

HTML5

HTML5 es una de las tecnologías que estoy aprendiendo para crear y organizar el contenido de una página web.

CSS

CSS es una tecnología que estoy aprendiendo para modificar la apariencia y el diseño de una página web.

JavaScript

JavaScript es una tecnología que nos permite agregar interacción y comportamiento a una página web.

Lo que estoy aprendiendo

  • Crear la estructura de una página web con HTML5.
  • Modificar la apariencia de una página utilizando CSS.
  • Agregar interacción a una página web con JavaScript.
